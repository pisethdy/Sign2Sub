⚙️ Technology

Built on Cutting-Edge AI

Extracts 147-dimensional spatial landmarks using MediaPipe Holistic and a BiLSTM network with multi-head attention — engineered for accuracy, speed, and reliability.

💻
Layer 1

Frontend

Captures continuous hand movement in real time directly through the browser. MediaPipe Holistic extracts 147-dimensional spatial landmarks from live webcam streams with zero hardware requirements.

MediaPipe Holistic WebRTC JavaScript 147 Landmarks
⚙️
Layer 2

Backend

Processes captured frames with OpenCV for robust gesture recognition and normalization. Handles real-time data pipelines, frame buffering, and landmark preprocessing for AI inference.

OpenCV Python FastAPI WebSocket
🧠
Layer 3

AI / ML

Our BiLSTM network with multi-head attention learns temporal patterns in continuous signing. A 0.4 confidence threshold prevents hallucination and ensures subtitle accuracy even in ambiguous gesture sequences.

BiLSTM Multi-Head Attention TensorFlow 0.4 Threshold
🔬
Why BiLSTM + Multi-Head Attention? Sign language is inherently temporal — meaning depends on the sequence and timing of gestures, not just individual frames. Bidirectional LSTM captures forward and backward context while multi-head attention focuses on the most discriminative landmark movements, giving Sign2Sub state-of-the-art accuracy for continuous, real-world signing scenarios.
